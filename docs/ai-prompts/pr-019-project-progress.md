# PR #19: 프로젝트 진행 현황 갱신

## 개요

- 브랜치: `docs/update-project-progress`
- PR: #19
- 작성일: 2026-08-06
- 작업 목적: 오래된 프로젝트 진행 현황 문서를 현재 구현과 배포 상태에 맞게 갱신한다.

## 주요 요청

1. 저장소에 있는 프로젝트 현황 문서를 확인한다.
2. 전체 프로젝트 상황을 다시 파악해 문서를 업데이트한다.
3. 변경 내용을 커밋하고 푸시한 뒤 PR을 생성한다.

## AI와 논의한 내용

### 문서의 기준 범위

기존 문서는 핵심 게임 루프 연결 전 상태를 설명하고 있었다. 현재 `main`의 코드, 씬, Build Settings, GitHub Actions와 병합된 PR 기록을 대조해 병합된 기능만 완료 상태로 기록하고, 아직 병합되지 않은 WebGL 한글 폰트 작업은 진행 중으로 구분했다.

### 런타임 상태와 영구 저장 구분

수집물, 골드와 배터리는 정적 상태를 사용해 씬 전환 간 공유되지만 게임 재시작 후에는 유지되지 않는다. 업그레이드 레벨은 `BaseScene`의 컨트롤러 인스턴스에 있어 씬 재진입 시에도 초기화된다. 이를 단순히 "글로벌 공유"로 표현하지 않고 데이터별 유지 범위를 표로 분리했다.

## 주요 결정

- 문서 전용 브랜치를 기존 한글 폰트 PR과 분리해 `main`에서 생성했다.
- 구현 현황뿐 아니라 전체 플레이 흐름, 상태 유지 범위, 빌드·배포, 기술 부채와 다음 작업 순서를 함께 기록했다.
- 저장소에서 확인 가능한 사실과 기존 수동 검증 기록을 구분했다.
- 코드, 씬과 에셋은 변경하지 않았다.

## 변경된 주요 파일

- `docs/PROJECT_PROGRESS.md`
- `docs/ai-prompts/pr-019-project-progress.md`

## 검증 내용

- 주요 스크립트, 세 씬, Build Settings와 WebGL 배포 워크플로를 문서 내용과 대조했다.
- 최근 병합 커밋과 PR #14~#17의 AI 협업 기록을 확인했다.
- 오래된 `SampleScene`, 미구현 수집 시스템과 빌드 미등록 설명이 제거됐는지 검색했다.
- `git diff --check`를 통과했다.

## AI 활용 범위

AI가 저장소 조사, 구현 상태 분류, 문서 작성, 정적 검증과 Git 작업을 수행했다. 사용자는 전체 프로젝트 상황을 다시 파악해 문서를 업데이트하고 PR까지 생성하도록 요청했다.
