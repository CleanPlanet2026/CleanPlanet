# PR #20: 업그레이드 화면 텍스트 잘림 수정

## 개요

- 브랜치: `fix/upgrade-ui-clipping`
- PR: #20
- 작성일: 2026-08-06
- 작업 목적: 업그레이드 화면 우상단 부제와 좌하단 상태 범례가 잘리지 않고 안정적으로 표시되게 한다.

## 주요 요청

1. 업그레이드 화면의 `SYSTEM UPGRADE TREE` 텍스트 잘림을 수정한다.
2. 좌하단의 완료·구매 가능·잠김 범례를 다시 제대로 표시한다.

## AI와 논의한 내용

### 폰트 변경과 반응형 레이아웃

WebGL 한글 폰트 수정 이후에도 안정적으로 보이도록 PR #18 브랜치의 `BaseScene`을 기준으로 UI 구조를 확인했다. 부제는 헤더 폭의 30%만 사용하고 범례는 두 줄이 될 수 있는 문구에 36px 높이만 사용하고 있어, 폰트 폭과 화면 비율에 따라 잘릴 여지가 있었다.

## 주요 결정

- 부제 영역을 헤더 폭의 42%로 넓힌다.
- 상단 헤더 패널 높이를 88px에서 64px로 줄인다.
- 범례를 상세 패널까지 가로지르지 않고 스킬 트리 영역의 74% 폭에 맞춘다.
- 범례는 한 줄로 표시하고, 실제 노드와 동일한 빈 박스 테두리를 강화 완료(민트), 업그레이드 가능(주황), 선행 강화 필요(회색) 상태로 구분한다.
- 스크립트 추가 없이 기존 uGUI RectTransform만 최소 수정한다.

## 변경된 주요 파일
