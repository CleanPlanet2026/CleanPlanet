# PR #9: 업그레이드 스킬 트리 UI 추가

## 개요

- 브랜치: `feature/upgrade-panel-workspace`
- PR: #9
- 작성일: 2026-08-03
- 작업 목적: 업그레이드 스킬 트리 화면을 구성하고 드래그·확대·축소·초기화 기능을 제공한다.

## 주요 요청

1. 업그레이드 패널에 스킬 트리 UI를 구성한다.
2. 변경 내용을 확인해 커밋하고 원격 브랜치에 푸시한다.
3. 프로젝트 문서 규칙을 확인하고 AI 협업 기록과 PR을 생성한다.
4. 스킬 노드를 클릭하면 선택 상태가 표시되고 오른쪽 상세 설명이 해당 옵션에 맞게 변경되도록 한다.

## AI와 논의한 내용

### 스킬 트리 탐색 방식

큰 스킬 트리를 제한된 화면에서 탐색할 수 있도록 뷰포트에 드래그 이동과 확대·축소 기능을 적용했다. 화면 크기에 맞는 기본 배율을 계산하고 콘텐츠가 지나치게 벗어나지 않도록 위치를 제한했다.

### Git 변경 범위

Unity가 자동으로 변경한 프로젝트 설정 파일은 기능과 직접 관련이 없어 커밋에서 제외했다. `BaseScene.unity`, `SkillTreeViewportController.cs`, 해당 메타 파일만 기능 커밋에 포함했다.

### 스킬 노드 선택과 상세 정보 표시

기존 씬에는 로봇 코어를 포함한 16개 스킬 노드와 오른쪽 상세 패널이 시각 요소로만 존재했다. 별도의 업그레이드 데이터나 구매 시스템은 아직 없으므로, 이번 작업에서는 `SkillTreeDetailController`가 각 버튼과 표시 데이터를 직렬화해 관리하고 클릭 시 상세 패널을 갱신하도록 구성했다.

실제 골드 차감과 업그레이드 효과 적용은 현재 범위에서 제외하고, 노드 선택 반응과 정보 표시만 구현했다.

## 주요 결정

- 스킬 트리는 마우스 드래그로 이동한다.
- 마우스 휠과 UI 버튼으로 확대·축소한다.
- 초기화 버튼으로 기본 배율과 중앙 위치를 복원한다.
- 기능과 무관한 Unity 설정 변경은 PR에 포함하지 않는다.
- 로봇 코어를 포함한 16개 노드 모두 선택할 수 있게 한다.
- 선택 시 상태·스킬명·분류·설명·현재 효과·강화 후 효과·비용을 갱신한다.
- 기본 선택 노드는 `패턴 학습 II`로 설정한다.
- 실제 구매와 골드 차감은 후속 작업으로 분리한다.
