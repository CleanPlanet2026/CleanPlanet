## AI와 논의한 내용

### 조사 기준 브랜치

작업 시작 시 체크아웃되어 있던 기능 브랜치는 최신 `main`보다 이전 상태였다. 현재 진행 상황을 누락하지 않도록 원격 변경을 확인하고 `origin/main`에서 문서 브랜치를 생성해 조사 기준으로 삼았다.

### 구현 상태의 구분

코드 파일 존재 여부만으로 완료를 판단하지 않았다. 씬 배선, Build Settings, 병합된 PR의 검증 기록을 함께 확인하고 각 영역을 시연 가능, 부분 완료, 미구현 상태로 구분했다. 병합된 기능이라도 전체 게임 루프에 연결되지 않은 경우 이를 별도 위험으로 기록했다.

## 주요 결정

- 기준 시점과 기준 커밋을 문서 상단에 명시한다.
- 기능별 상태를 표로 요약하고 시스템별 상세 내용을 함께 제공한다.
- 과거 PR의 수동 검증 기록과 현재 자동화 테스트 부재를 구분한다.
- 핵심 게임 루프 연결, 쓰레기 수집 재구현, 업그레이드 실제 기능과 저장 기능을 주요 후속 작업으로 제안한다.

## AI 활용 범위

AI가 저장소 현황 조사, 구현 상태 분류, 기술 부채 식별과 문서 작성을 수행했다. 기능 완료 여부는 현재 코드·씬 구성과 기존 PR 검증 기록을 근거로 판단했으며, 새로운 게임 기능이나 프로젝트 설정은 변경하지 않았다.
