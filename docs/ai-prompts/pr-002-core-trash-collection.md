# PR #2: 핵심 쓰레기 수집 게임플레이 추가

## 개요

- 브랜치: `feature/core-gameplay-foundation`
- PR: #2
- 작성일: 2026-08-01
- 작업 목적: 쓰레기 클릭, 이동, 처리, 보상으로 이어지는 기본 게임 흐름 구현

## 주요 요청

1. 쓰레기를 클릭하면 플레이어가 해당 위치로 이동하도록 한다.
2. 도착한 플레이어가 일정 시간 동안 쓰레기를 처리하도록 한다.
3. 처리가 끝나면 쓰레기 보상을 플레이어 인벤토리에 추가한다.
4. 키보드 이동은 지원하지 않고 클릭 기반 이동만 유지한다.
5. AI와 협업한 프롬프트 및 의사결정 내용을 PR 단위로 문서화한다.

## AI와 논의한 내용

### 플레이어 이동 방식

초기 `PlayerMovement`에는 Input System의 이동 액션을 받는 키보드 이동 코드가 포함되어 있었다. 씬을 점검한 결과 이동 액션 참조가 연결되지 않아 실제 키보드 이동은 동작하지 않는 상태였다. 사용자 결정에 따라 키보드 입력 처리와 씬의 직렬화 항목을 제거하고, 쓰레기를 클릭해 설정된 목적지로 이동하는 기능만 유지했다.

### 쓰레기 수집 흐름

쓰레기를 클릭하면 대상을 선점하고 플레이어가 상호작용 위치로 이동한 뒤 처리 시간을 적용하도록 구성했다. 처리가 완료되면 인벤토리에 보상을 추가하고 쓰레기 오브젝트를 반환하는 흐름으로 역할을 분리했다.

### 협업 기록 방식

원본 대화 전체를 저장하기보다 주요 요청, 논의, 결정, 변경 파일, 검증 결과와 AI 활용 범위를 요약하기로 했다. 상세 작성 규칙과 재사용 가능한 템플릿은 `docs/ai-prompts/README.md`에서 관리한다.

## 주요 결정

- 플레이어는 키보드로 직접 이동하지 않는다.
- 플레이어 이동은 쓰레기 클릭으로 설정된 목적지를 통해서만 시작한다.
- `PlayerMovement`는 목적지 이동을 담당한다.
- `PlayerTrashCollector`는 대상 선택, 이동 요청, 처리 흐름을 담당한다.
- 쓰레기 보상 수량은 `TrashInventory`에서 관리한다.
- 별도 아트가 없어도 기능을 확인할 수 있도록 임시 스프라이트를 사용한다.

## 검증 내용

- 키보드 이동 코드와 씬의 빈 이동 액션 항목을 제거했다.
- 클릭 기반 목적지 이동과 쓰레기 처리 호출이 유지되는 것을 확인했다.
- `git diff --check` 검사를 통과했다.
