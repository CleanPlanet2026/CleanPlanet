# PR #4: 베이스 화면 전환 기능 추가

## 개요

- 브랜치: `feature/base-scene-navigation`
- PR: #4
- 작성일: 2026-08-01
- 작업 목적: 하나의 베이스 씬에서 감정 로봇 화면과 업그레이드 화면을 탭으로 전환하는 기본 흐름 구현

## 주요 요청

1. 수집 단계 다음에 사용할 베이스 화면을 준비한다.
2. 감정 로봇 화면과 스킬 트리 화면 사이를 전환할 수 있게 한다.
3. 좌상단에 두 화면의 탭을 표시하고 현재 탭을 선택 상태로 표현한다.
4. 탭 이름을 `감정 로봇`과 `업그레이드`로 변경한다.
5. `탐험` 버튼을 우측 하단에 배치하고 아직 기능은 연결하지 않는다.
6. 탐험 버튼을 클릭한 뒤 흰색으로 유지되는 선택 상태 문제를 해결한다.
7. 최종 플레이 모드 검증은 사용자가 Unity에서 직접 수행한다.

## AI와 논의한 내용

### 씬과 패널 구조

처음에는 감정 로봇과 스킬 트리를 각각 독립된 Unity 씬으로 구현했다. 공통 탭과 탐험 버튼이 계속 유지되는 화면이라는 점을 다시 검토한 결과, 별도의 씬보다 하나의 `BaseScene` 안에서 패널을 전환하는 구조가 더 적합하다고 판단했다. 기존 두 씬과 씬 전환 스크립트를 제거하고 `Emotion Robot Panel`과 `Upgrade Panel`을 하나의 씬에 배치했다.

### 탭 전환 방식

`BaseViewController`가 두 패널과 두 탭 버튼의 참조를 직렬화해 관리한다. 감정 로봇 탭을 누르면 감정 로봇 패널만 활성화하고, 업그레이드 탭을 누르면 업그레이드 패널만 활성화한다. 현재 화면의 탭은 비활성화해 선택 색상을 유지한다.

### 탐험 버튼 선택 상태

탐험 버튼은 클릭 기능을 연결하지 않은 상태로 우측 하단에 배치했다. 클릭 후 선택 상태가 흰색으로 남지 않도록 버튼 내비게이션을 비활성화하고 선택 색상을 기본 색상과 동일하게 설정했다.

## 주요 결정

- 베이스 화면은 하나의 `BaseScene`으로 구성한다.
- 감정 로봇과 업그레이드는 별도 씬이 아닌 패널로 관리한다.
- 좌상단에 `감정 로봇`과 `업그레이드` 탭을 배치한다.
- 현재 패널의 탭은 선택 색상과 비활성 상태로 표시한다.
- 탐험 버튼은 우측 하단에 배치하고 클릭 기능은 연결하지 않는다.
- 기존 `SampleScene`은 유지하고 `BaseScene`을 빌드 설정에 추가한다.
- 실제 감정 로봇·업그레이드·탐험 콘텐츠와 수집 완료 후 베이스 진입은 후속 작업으로 남긴다.

## 변경된 주요 파일

- `Assets/Scripts/UI/BaseViewController.cs`
- `Assets/Scenes/BaseScene.unity`
- `ProjectSettings/EditorBuildSettings.asset`

## 검증 내용

- `BaseScene`에 감정 로봇 패널과 업그레이드 패널이 함께 존재하는 것을 확인했다.
- `BaseViewController`에 두 패널과 두 탭 버튼의 직렬화 참조가 모두 연결된 것을 확인했다.
- 최초 상태에서 감정 로봇 패널과 탭이 선택된 것을 확인했다.
- 탐험 버튼이 우측 하단 앵커를 사용하고 클릭 이벤트가 비어 있는 것을 확인했다.
- 탐험 버튼의 내비게이션이 비활성화되고 선택 색상이 기본 색상과 동일한 것을 확인했다.
- 빌드 설정에 기존 수집 씬과 단일 베이스 씬만 등록된 것을 확인했다.
- 플레이 모드에서의 화면 전환과 시각적 확인은 사용자 검증 항목으로 남겼다.

## AI 활용 범위

AI는 기존 씬 구조 조사, 단일 베이스 씬 구조 설계, `BaseViewController` 구현, UI와 직렬화 참조 생성, 기존 씬 및 전환 코드 정리, 정적 구성 확인, Git 커밋과 PR 갱신을 지원했다. 단일 베이스 씬으로 변경하고 탭 이름·탐험 버튼 위치·검증 방식을 확정한 것은 사용자의 결정이다.
