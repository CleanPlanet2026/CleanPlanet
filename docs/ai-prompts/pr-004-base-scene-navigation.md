# PR #4: 베이스 화면과 로봇 감정 미리보기

## 개요

- 브랜치: `feature/base-scene-navigation`
- PR: #4
- 작성일: 2026-08-01
- 목적: 하나의 베이스 씬에서 감정 로봇과 업그레이드 화면을 전환하고, 수집물 감정 과정을 임시 UI로 확인한다.

## 주요 요청

1. 감정 로봇과 업그레이드 화면을 좌상단 탭으로 전환한다.
2. 현재 탭은 선택된 상태로 표시하고, 우측 하단에 아직 연결하지 않은 `탐험` 버튼을 둔다.
3. 탐험 버튼을 누른 뒤 흰색 선택 상태가 남지 않게 한다.
4. 고철, 유리, 전자품, 보석이 로봇 머리로 들어가 골드로 바뀌는 과정을 임시 UI로 만든다.
5. 오른쪽 큰 눈에는 1·2·4·8·16배 룰렛을 표시한다.
6. 감정 속도를 빠르게 하고, 실제 수집물 UI 오브젝트가 머리를 통과해 투명한 왼쪽 눈 내부로 떨어지는 모습을 보여 준다.
7. 업그레이드 탭으로 이동해도 감정 처리가 계속 진행되게 한다.
8. 보간 애니메이션 대신 실제 2D 중력과 충돌을 적용하고, 여러 수집물을 연속으로 붓듯이 투하한다.
9. 수집물이 머리 하단 데드라인에 닿는 순간의 룰렛 배율로 골드를 계산한다.

## 논의와 결정

### 단일 베이스 씬

공통 탭과 탐험 버튼이 계속 유지되는 화면이므로 별도 Unity 씬 두 개 대신 `BaseScene` 안에서 `Emotion Robot Panel`과 `Upgrade Panel`을 전환한다. `BaseViewController`가 패널 활성 상태와 탭 선택 상태를 관리한다.

### 버튼 상태

현재 탭 버튼은 비활성화해 눌린 상태로 보이게 한다. 탐험 버튼은 기능을 연결하지 않고, 내비게이션을 비활성화하고 선택 색상을 기본 색상과 같게 설정해 클릭 후 흰색으로 남지 않게 한다.

### 감정 미리보기

실제 인벤토리와 재화 데이터는 연결하지 않는다. 수집물은 `Rigidbody2D`와 `CircleCollider2D`가 붙은 하나의 원형 오브젝트로 만들고, 0.08초 간격으로 연속 투하한다. 좌우 위치, 수평 속도, 회전을 조금씩 무작위로 적용해 여러 수집물을 한꺼번에 붓는 느낌을 낸다.

머리 내부에는 좌우 벽과 경사진 유도 벽을 실제 `BoxCollider2D`로 배치한다. 같은 수집물 오브젝트가 머리 중앙에서 왼쪽으로 유도되어 투명한 눈 뒤를 지나가므로 외부·내부 표시용 복제 오브젝트를 사용하지 않는다. 머리 외장은 수집물보다 앞에 렌더링하고 왼쪽 눈 영역만 반투명하게 열어 내부 이동이 실제로 보이게 한다.

오른쪽 눈의 룰렛은 0.05초 간격으로 계속 순환한다. 머리 하단의 트리거형 데드라인에 수집물이 닿으면 그 순간 `CurrentMultiplier`를 읽어 임시 골드를 계산하고 수집물은 풀로 반환한다.

### 탭 전환 중 처리 유지

물리 처리 루트는 감정 패널의 자식이 아니라 공통 Canvas의 자식으로 배치한다. 업그레이드 탭에서는 `CanvasGroup`의 투명도만 0으로 바꾸므로 물리 시뮬레이션, 룰렛, 임시 골드는 계속 진행된다.

## 검증

- `BaseScene`에 감정 로봇과 업그레이드 패널이 함께 존재하는지 확인했다.
- 탭, 패널, 탐험 버튼의 직렬화 참조와 초기 상태를 확인했다.
- 수집물 프리팹에 `Rigidbody2D`, `CircleCollider2D`, 이미지와 이름 참조가 있는지 확인했다.
- 물리 루트에 좌우 벽, 경사 유도 벽, 하단 데드라인이 있는지 확인했다.
- 단일 수집물이 투명한 왼쪽 눈 뒤를 지나도록 렌더링 순서와 머리 외장 구성을 확인했다.
- 데드라인 진입 시 현재 룰렛 배율을 읽어 골드를 계산하는 코드 경로를 확인했다.
- 물리 처리 루트가 감정 패널 밖의 공통 Canvas 아래에 있고 `CanvasGroup`으로만 숨겨지는지 확인했다.
- 0.08초 투하 간격과 0.05초 룰렛 간격이 씬에 저장됐는지 확인했다.
- Unity 배치 모드에서 씬 생성 스크립트 컴파일과 저장을 확인했다.
- 플레이 모드의 시각적 동작은 사용자 직접 검증 항목으로 남겼다.

## AI 기여 범위

AI는 기존 구조 조사, 단일 베이스 씬 구성, 탭 전환 코드, 버튼 상태 설정, 감정 미리보기 코드와 UI 참조 생성, 낙하 구조 및 처리 지속 방식 구현, 정적 검증, Git 커밋과 PR 갱신을 지원했다. 최종 화면의 미술 리소스와 실제 수집·재화 데이터 연결은 포함하지 않았다.
