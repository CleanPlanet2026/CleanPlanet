# PR #4: 베이스 씬 전환 기능 추가

## 개요

- 브랜치: `feature/base-scene-navigation`
- PR: #4
- 작성일: 2026-08-01
- 작업 목적: 감정 로봇 화면과 스킬 트리 화면 사이를 버튼으로 전환하는 베이스 씬 흐름 구현

## 주요 요청

1. 수집 단계 다음에 사용할 베이스 씬 흐름을 준비한다.
2. 감정 로봇 장면과 스킬 트리 장면 사이를 서로 전환할 수 있게 한다.
3. 이번 작업에서는 실제 콘텐츠보다 씬 전환까지만 구현한다.
4. 두 씬의 좌상단에 감정·스킬 트리 탭을 배치하고 현재 씬을 선택 상태로 표시한다.
5. 두 씬의 좌하단에 아직 기능을 연결하지 않은 탐험 버튼을 배치한다.

## AI와 논의한 내용

### 구현 범위

감정 로봇과 스킬 트리를 각각 독립된 Unity 씬으로 만들고, 각 씬에 상대 씬으로 이동하는 버튼을 두기로 했다. 사용자가 요청한 범위에 맞춰 실제 감정 상태 표현, 스킬 노드, 수집 완료 후 자동 진입은 이번 PR에서 제외했다.

### 씬 전환 방식

씬마다 전환 로직을 중복하지 않도록 `SceneLoader`가 씬 이름을 받아 유효성을 확인한 뒤 `SceneManager.LoadScene`을 호출하도록 구성했다. 버튼은 인스펙터의 영구 이벤트를 통해 대상 씬 이름과 연결했다.

### 화면 내비게이션

기존 중앙 전환 버튼을 제거하고 두 씬 모두 좌상단에 감정·스킬 트리 탭을 함께 배치했다. 현재 씬의 탭은 선택 색상을 적용하고 상호작용을 비활성화해 눌린 상태를 유지하며, 다른 탭만 해당 씬으로 이동하도록 연결했다. 좌하단 탐험 버튼은 후속 기능을 위해 배치만 하고 클릭 이벤트는 비워 두었다.

### Unity 검증

프로젝트가 Unity 에디터에서 열려 있어 첫 배치 실행이 중단됐다. 사용자가 에디터를 종료한 뒤 Unity 6 배치 모드에서 씬을 생성하고, 일회성 생성 도구를 제거한 최종 상태로 다시 컴파일을 확인했다.

## 주요 결정

- 감정 로봇과 스킬 트리를 별도의 Unity 씬으로 구성한다.
- 두 씬은 화면 버튼으로 양방향 전환한다.
- 좌상단 탭 두 개는 모든 베이스 씬에서 동일하게 표시한다.
- 현재 씬 탭은 선택 색상과 비활성 상태로 표시한다.
- 좌하단 탐험 버튼은 배치만 하고 동작은 연결하지 않는다.
- 씬 전환은 공용 `SceneLoader`가 담당한다.
- 기존 `SampleScene`은 유지하고 신규 씬 두 개를 빌드 설정에 추가한다.
- 실제 베이스 콘텐츠와 수집 완료 후 자동 전환은 후속 작업으로 남긴다.

## 변경된 주요 파일

- `Assets/Scripts/Core/SceneLoader.cs`
- `Assets/Scenes/EmotionRobotScene.unity`
- `Assets/Scenes/SkillTreeScene.unity`
- `ProjectSettings/EditorBuildSettings.asset`

## 검증 내용

- Unity 6 배치 모드가 오류 없이 종료되는 것을 확인했다.
- 최종 Unity 로그에 C# 컴파일 오류가 없음을 확인했다.
- `EmotionRobotScene` 버튼이 `SkillTreeScene`을 대상으로 호출하는 것을 확인했다.
- `SkillTreeScene` 버튼이 `EmotionRobotScene`을 대상으로 호출하는 것을 확인했다.
- 각 씬의 현재 탭만 상호작용이 비활성화되고 반대 탭에만 씬 전환 이벤트가 있는 것을 확인했다.
- 두 씬의 탐험 버튼에 클릭 이벤트가 연결되지 않은 것을 확인했다.
- 기존 수집 씬과 신규 씬 두 개가 빌드 설정에 등록된 것을 확인했다.

## AI 활용 범위

AI는 기존 씬과 빌드 설정 조사, 전환 구조 설계, `SceneLoader` 구현, 두 Unity 씬 생성, 버튼 이벤트 연결, Unity 배치 검증, Git 브랜치·커밋·PR 작업을 지원했다. 구현 범위를 씬 전환으로 제한하고 Unity 에디터를 종료해 검증을 진행하도록 한 결정은 사용자가 내렸다.
