# PR #13: 런타임 업그레이드 상태 추가

## 개요

- 브랜치: `feature/runtime-upgrade-state`
- PR: #13
- 작성일: 2026-08-04
- 작업 목적: 업그레이드 상태를 파일에 저장하지 않고 현재 실행 중에만 유지하며, 업그레이드 UI에서 상태 변화를 확인할 수 있게 한다.

## 주요 요청

1. 강화 상태를 런타임에만 저장한다.
2. 기존 업그레이드 패널에 런타임 강화 동작을 연결한다.
3. `패턴 학습 II` 노드에 고정된 오렌지색 초기 강조를 제거한다.

## AI와 논의한 내용

### 저장 범위

영구 저장은 현재 해커톤 범위에서 제외했다. 강화 레벨은 일반 C# 객체의 Dictionary에만 저장해 Play Mode가 끝나거나 게임이 종료되면 초기화되도록 구성했다.

### 기존 UI 데이터 재사용

현재 스킬 트리에 직렬화된 현재 효과, 다음 효과와 비용 문자열을 그대로 사용했다. 각 노드에 안정적인 업그레이드 ID와 초기/최대 레벨만 추가하고, 별도의 ScriptableObject 데이터 구조나 실제 게임 효과 시스템은 도입하지 않았다.

### 고정 강조 색상 제거

`패턴 학습 II`의 버튼과 Image에 직접 저장된 오렌지색은 실제 선택 상태와 연동되지 않았다. 이를 인접 비선택 노드와 같은 중립색으로 변경하고, 상세 패널의 기본 선택 인덱스와 클릭 동작은 유지했다.

## 주요 결정

- `UpgradeRuntimeState`는 Unity 컴포넌트가 아닌 런타임 메모리 전용 클래스로 구현한다.
- 현재 단계에서는 로봇 코어를 제외한 각 노드를 한 번 강화할 수 있다.
- 강화 버튼을 누르면 레벨, 상태, 현재/다음 효과, 비용과 버튼 활성 상태를 즉시 갱신한다.
- `패턴 학습 II`에 고정된 오렌지색 외형은 제거한다.
- 골드 차감, 실제 능력치 적용과 영구 저장은 후속 작업으로 분리한다.

## 변경된 주요 파일

- `Assets/Scripts/Upgrade/UpgradeRuntimeState.cs`
- `Assets/Scripts/UI/SkillTreeDetailController.cs`
- `Assets/Scenes/BaseScene.unity`

## 검증 내용

- `BaseScene`의 16개 스킬 노드에 고유 ID와 레벨 값이 설정됐는지 정적으로 확인했다.
- 상세 컨트롤러에 업그레이드 버튼 참조가 연결됐는지 확인했다.
- `패턴 학습 II`의 버튼 상태 색상과 Image 색상이 중립색으로 변경됐는지 확인했다.
- `git diff --check`를 통과했다.
- Unity 에디터가 이미 프로젝트를 열고 있어 별도 배치 모드 컴파일 검증은 수행하지 못했다.

## AI 활용 범위

AI가 기존 업그레이드 UI와 재화 구조를 분석하고, 런타임 상태 클래스 구현, UI 연결, 씬 직렬화 설정과 정적 검증을 수행했다. 실제 재화 소비, 능력치 효과와 영구 저장 정책은 이번 범위에 포함하지 않았다.

## 후속 작업

- Unity Play Mode에서 각 노드의 강화 버튼 동작과 패널 재진입 후 상태 유지를 확인한다.
- 재화 차감과 구매 가능 조건을 연결한다.
- 실제 능력치 효과 적용을 연결한다.
- 필요할 때 런타임 상태를 JSON 저장 데이터로 변환한다.
