# PR #18: WebGL 한글 폰트 적용

## 개요

- 브랜치: `fix/title-webgl-font`
- PR: #18
- 작성일: 2026-08-06
- 작업 목적: WebGL 타이틀과 베이스 화면에서 한글 텍스트가 표시되지 않는 문제를 수정한다.

## 주요 요청

1. 브라우저 타이틀 화면에서 보이지 않는 텍스트의 원인을 확인한다.
2. 타이틀 화면 폰트를 WebGL에 포함되는 한글 폰트로 교체한다.
3. 베이스 화면 전환 패널을 포함한 기본 폰트 참조도 함께 교체한다.

## AI와 논의한 내용

### WebGL 한글 표시

`TitleScene`의 제목, 부제, 시작 버튼과 `BaseScene`의 일부 UI가 Unity 기본 `LegacyRuntime.ttf`를 참조하고 있음을 확인했다. 기본 런타임 폰트 대신 프로젝트에서 기존 UI에 사용 중인 `Galmuri11.ttf`를 사용하기로 결정했다.

## 주요 결정

- 새 폰트를 추가하지 않고 기존 `Assets/Art/Fonts/Galmuri11.ttf`를 재사용한다.
- 타이틀의 세 Text 컴포넌트와 베이스 씬의 남은 기본 폰트 참조를 변경한다.

## 변경된 주요 파일

- `Assets/Scenes/TitleScene.unity`
- `Assets/Scenes/BaseScene.unity`

## 검증 내용

- 타이틀 씬의 세 Text 컴포넌트가 모두 `Galmuri11.ttf` GUID를 참조하는지 확인했다.
- 베이스 씬의 기본 런타임 폰트 참조 10개가 모두 `Galmuri11.ttf`로 변경됐는지 확인했다.
- 두 씬에 기본 런타임 폰트 참조가 남지 않았는지 확인했다.
- 실제 WebGL 표시는 병합 후 자동 배포 결과에서 확인한다.

## AI 사용 범위

AI는 타이틀 씬의 폰트 참조와 프로젝트 내 한글 폰트 에셋을 분석하고 씬 참조를 수정했다. 사용자는 기존 한글 폰트로 교체하도록 결정했다.

## 후속 작업

- PR 병합 후 WebGL 자동 배포가 완료되면 브라우저에서 제목, 부제, 시작 버튼을 확인한다.
